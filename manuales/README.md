## De dónde salen

Los manuales se crean y se editan como artefactos en claude.ai, que siguen siendo la versión principal para ver y actualizar:

- Marca NUMMEROS: https://claude.ai/artifact/7QTPsyEFrVgzLC1gEkZBAG
- Marca CONTAX: https://claude.ai/artifact/7RhBmi8VXEJFA5PHtrCi5j

Esta carpeta es la copia de respaldo en GitHub, para que el editor, los sistemas y Claude Code tengan todo a mano.

## Regla para mantenerlos iguales

Cada vez que se actualice un artefacto de marca, hay que volver a copiar aquí su versión nueva, con todos sus archivos. Así el artefacto y GitHub nunca quedan distintos.

La única diferencia entre la copia y el artefacto es un cambio en `index.html`: si la página no está dentro de claude.ai, los botones de Descargar usan la descarga normal del navegador. Ese ajuste hay que repetirlo en cada copia nueva.

## Qué usar en los sistemas

- Colores y letras listos para sistemas web: `nummeros/descargas/nummeros-tokens.css` y `contax/descargas/contax-tokens.css`.
- Logos en vector: `nummeros/logos/` y `contax/logos/`. En PNG: carpeta `png/` de cada manual.
- Íconos de app y favicon: carpeta `iconos/` de cada manual.
- Reglas completas: el PDF de cada manual en `descargas/`. Para CONTAX también está el manual de la empresa en texto: `contax/manual/contax-manual.md`.
