# Carpeta `tutoriales/` — videos tutoriales de CONTAX y NUMMEROS

- `index.json` — lista de videos (nombre, archivo, póster, formato, duración, estado y en qué sistemas va).
- Cada video se publica con el sitio: `https://edithornummeros.contaxbolivia.com/tutoriales/<archivo>.mp4`
- Los sistemas (pasarela, Portal de Clientes, Portal de Repartidores, etc.) pueden leer `https://edithornummeros.contaxbolivia.com/tutoriales/index.json` y mostrar el video que les corresponde según `sistemas`.
- En EdiThor se ven en la pestaña **Claude → Videos tutoriales**.
